It was the first time that I made a PCB and, even though I had a hard time connecting everything, it was really fun. I used KiCad and I looked online for the things I couldn't find on Hack Club's guide. This PCB 
was made with the intention of being like a Tamagotchi, where you have a little virtual pet to play with. To make different versions of the pet, I used LibreSprite, which is an app where you can draw pixel art. 
You can check them in the PNG archives of this project. The PCB has this format because I really like math and, when I was searching for fractals, it appeared in a math question on the OBMEP site (one of the most 
important Brazilian math olympiads). I think the pets I liked the most were the pink bird and the porcupine.
